# 参数核查清单

出图前必须跑完这份清单。**命中任一项 → 停下来问用户，不许自行决策。**

---

## 一、几何自洽性检查（数学层面）

逐条验算，任何一个不成立都是矛盾：

### 1. 配合关系
```
孔径 ≥ 轴径            （装配可行性）
孔径 - 轴径 = 间隙     （间隙是否合理，过小无法装配，过大失去定位作用）
壁厚的 2 倍 = 外径 - 内径 > 0
```

### 2. 轴向尺寸
```
各分段长度之和 = 总长
定位尺寸 ≤ 总长
定位尺寸 + 该段长度 ≤ 总长
伸出量 = 总长 - 定位 - 嵌入段长度 ≥ 0
```

### 3. 径向尺寸
```
外径 > 内径
外径 - 内径 是偶数倍的壁厚（对称回转体）
```

### 4. 图号与几何的一致性
图号里的数字往往编码了关键尺寸（如 `DC1616-0.45(12-3.4)` 中 0.45 = 内导体直径）。
**务必核对图号数字与用户报的实际尺寸是否吻合**，不吻合要问。

### 5. 明细栏与几何的一致性
明细栏里的规格串（如 `0.45X6.9-T0.8`）要与模型几何对得上。对不上要问清楚每个字段的含义。

## 二、工艺合理性检查（工程层面）

能画出来 ≠ 能造出来。以下情况要提示用户（但不擅自改）：

| 项目 | 警戒线 | 说明 |
|---|---|---|
| 薄壁件壁厚 | < 0.5mm | 机加工/封接易变形、开裂 |
| 玻璃封接环厚 | < 0.3mm | 封接强度不足，易漏气 |
| 长径比 | > 20 | 细长轴易弯，需确认直线度要求 |
| 台阶过渡 | 无倒角/圆角 | 应力集中，且装配会卡 |
| 比例选择 | 图形超出图框 | 需换比例或换图幅 |
| 尺寸标注密度 | 关键尺寸漏标 | 无法加工/检验 |

提示时给出**具体数值和后果**，例如："玻璃环壁厚 0.35mm、高 1.6mm，封接工艺上偏薄，建议确认玻璃牌号与封接强度。"—— 把判断权留给用户。

## 三、完整性检查（图纸必填项）

用户没主动给、但图纸上必须有。缺失就问：

### 必问（影响几何或加工）
- [ ] **材料**（每个零件分别是什么牌号）
- [ ] **比例**（1:1 / 2:1 / 10:1 …，决定图面大小）
- [ ] **未注公差**（如 GB/T 1804-m、±0.1）
- [ ] **表面粗糙度**（Ra 值，或"其余 Ra6.3"）
- [ ] **倒角/圆角**（如"未注倒角 C0.2"）
- [ ] **数量**（单件 / 组件）

### 应问（影响图纸规范性）
- [ ] **图号命名规则**（新规格怎么编号）
- [ ] **视图方案**（几个视图？要不要局部放大？放大几倍？）
- [ ] **标题栏填写内容**（设计/审核/批准等栏目填什么、是否留空）
- [ ] **热处理/表面处理**（镀层、钝化、退火）
- [ ] **形位公差**（同轴度、垂直度等）
- [ ] **技术要求**条目

### 可后续确认（不阻塞出图）
- 设计/审核人签名与日期（留空即可）
- 重量、表面积（可由模型算出）

## 四、提问模板

用 `AskUserQuestion`，一次不超过 4 个问题。每个选项必须写清后果。

**几何矛盾类：**
> 问题：外导体中心孔 φ0.45 小于内导体 φ0.5，孔装不下轴（差 0.05）。怎么处理？
> - 中心孔改 φ1.2（推荐）：玻璃环厚 0.35，径向间隙充足
> - 内导体改 φ0.4：孔留 0.05 间隙
> - 我理解错了，实际是……

**缺参数类：**
> 问题：玻璃的外径（＝外导体中心孔径）取多少？
> - φ1.2（推荐）：与外导体 φ1.6 配合，环厚 0.2
> - φ1.0：环厚 0.1，偏薄
> - 其他值（我来指定）

**命名类：**
> 问题：内导体改成 φ0.5 后，新图号怎么定？
> - DC1616-0.5(12-3.4)（推荐）：沿用你的规则，中间数字即内导体直径
> - 仍用 DC1616-0.45(12-3.4)：图号不变，只改图形尺寸

**视图方案类：**
> 问题：你的原图只有一个 10:1 竖放主视图，我之前多画了 25:1 局部放大图。怎么处理？
> - 完全照你的：去掉局部放大（推荐）
> - 保留局部放大图

## 五、本次任务的真实案例（供参照）

用户原始需求：
> 外导体外径 1.6，外导体高度 1.6，内导体直径 0.5，内导体长度 12，内导体一端定位 3.4。
> 内外导体都是可伐 4G29，绝缘体是玻璃。

发现的问题与处理：

| # | 问题 | 类型 | 处理 |
|---|---|---|---|
| 1 | 用户先说"外导体中心孔距 0.45"，后又说"0.45 是中间可伐的直径"，最后说"忽略 0.45，按内导体 φ0.5×长 12 画" | 参数冲突 | 按最后指令；交付时列明 0.45 被忽略 |
| 2 | "内导体一端定位 3.4" 基准不明（从哪端量？） | 语义歧义 | 问：一端伸出外导体 3.4（另一端 7.0） |
| 3 | 外导体中心孔 0.45 < 内导体 φ0.5 | 几何矛盾 | 主动指出差 0.05，问用户；最终定为 φ1.2 |
| 4 | 玻璃外径未给 | 缺参数 | 问；定为 φ1.2 |
| 5 | 玻璃高度未给 | 缺参数 | 问；定为与外导体等高 1.6 |
| 6 | 文件名 `DC1616-0.45` 但标题栏写 `DC1614-0.45(6.9-1.5)-T0.8` | 图号不一致 | 提出待确认，按用户指定命名出图 |
| 7 | 明细栏 `0.45X6.9-T0.8` 与几何 φ0.45×长 12 对不上 | 明细栏矛盾 | 提出待确认，该栏暂留空 |
| 8 | 玻璃环壁厚 0.35mm、高 1.6mm | 工艺风险 | 主动提示偏薄，建议确认牌号与强度 |

**经验**：8 个问题里有 5 个是靠"主动提问"发现的，用户自己最初没意识到。这就是核查清单的价值。
